# По местам Достоевского

Литературный веб-гид по петербургским местам Фёдора Михайловича Достоевского: места из жизни писателя, места из его произведений, музеи и памятники, готовые и собираемые маршруты.

**Сайт:** https://ivanchuhonin.github.io/dostoevsky-web/web/index.html

## Возможности

- Каталог мест с фильтрами по категории и теме, поиск по названию и адресу
- Карточка места: описание, цитата, фотография, интерактивная карта (2GIS)
- Готовые тематические маршруты с картой и точками по порядку
- Конструктор собственного маршрута (2–5 мест)
- Страница «О нас» с формой обратной связи

## Технологии

Полностью статический сайт — чистые HTML/CSS/JavaScript, без сборки и бэкенда. Карта — 2GIS MapGL JS API.

## Запуск локально

Сервер не нужен — откройте `web/index.html` в браузере.

## Структура

```
web/
  index.html, catalog.html, place.html, routes.html, route.html, builder.html, about.html
  assets/
    css/        — стили
    js/         — логика страниц, конфиг API-ключей
    data/       — данные о местах и маршрутах (JSON)
    images/     — декоративные иллюстрации
    vendor/     — шрифты
```
